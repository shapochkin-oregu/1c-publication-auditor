# Changelog

Все заметные изменения проекта фиксируются в этом файле.

## [2.0.0] - 2026-09-16

Первая публичная версия 1C Publication Auditor.

### Добавлено

- read-only аудит публикаций 1С в Apache;
- проверка каталогов публикаций и `.htaccess`;
- анализ ожидаемых `Require ip`, `AllowOverride` и правил Apache;
- разбор `default.vrd` и определение файловых/серверных баз;
- проверка `1Cv8.1CD` для файловых баз;
- таймауты для файловых и сетевых проверок;
- поиск осиротевших каталогов публикаций;
- глубокий аудит связей Apache → Directory → VRD → база 1С;
- поиск дубликатов Alias, Directory, VRD base и повторно опубликованных баз;
- локальная веб-панель с фоновым сканированием и live-прогрессом;
- рекомендации по найденным проблемам;
- экспорт CSV и автономного HTML-отчёта;
- автоматическое открытие веб-интерфейса после запуска;
- проверка синтаксиса и runtime self-tests для Windows PowerShell 5.1.

### Публичная упаковка

- рабочий `config.json` заменён на обезличенный `config.example.json`;
- runtime-каталоги `data/` и `logs/` исключены из Git;
- release ZIP хранится вне дерева исходников и предназначен для GitHub Releases.

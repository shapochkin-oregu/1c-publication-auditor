# Release checklist

Чек-лист подготовки публичного релиза 1C Publication Auditor.

## Перед релизом

- [ ] Убедиться, что версия в `Scan-Worker.ps1`, `Start-Auditor.ps1` и `web/index.html` соответствует тегу релиза.
- [ ] Запустить `Check-Syntax.bat` на Windows PowerShell 5.1.
- [ ] Выполнить контрольное сканирование на тестовой/рабочей инфраструктуре.
- [ ] Проверить экспорт CSV и HTML.
- [ ] Убедиться, что `config.json`, `data/` и `logs/` отсутствуют в Git.
- [ ] Проверить исходники на реальные имена серверов, баз, пользователей, внутренние пути и секреты.
- [ ] Обновить `CHANGELOG.md`.
- [ ] Собрать ZIP из файлов релиза, добавив в архив `config.example.json` как шаблон конфигурации.

## GitHub Release

Рекомендуемый тег первой публичной версии: `v2.0.0`.

Название релиза: `1C Publication Auditor v2.0.0`.

Рекомендуемый asset: `1C-Publication-Auditor-v2.0.0.zip`.

ZIP не следует хранить в ветке `main`: бинарный архив прикладывается к GitHub Release.

## После публикации

- [ ] Скачать release asset с GitHub и проверить распаковку.
- [ ] Проверить запуск `Check-Syntax.bat` из скачанного архива.
- [ ] Проверить, что README указывает актуальную публичную версию.

# 1C Publication Auditor

**Текущая публичная версия: v2.0.0**

Read-only веб-аудитор публикаций 1С:Предприятия в Apache под Windows Server.

Приложение анализирует цепочку **Apache → публикация → каталог → .htaccess → default.vrd → база 1С** и показывает проблемы в локальной веб-панели.

## Возможности

- поиск публикаций 1С в `httpd.conf`;
- проверка существования каталогов публикаций;
- анализ `.htaccess` и ожидаемых `Require ip`;
- учёт `AllowOverride` и правил доступа Apache;
- чтение `default.vrd`;
- определение файловых и серверных баз 1С;
- проверка `1Cv8.1CD` для файловых баз;
- поиск дубликатов Alias, Directory и VRD base;
- обнаружение повторной публикации одной базы;
- аудит связей Apache → Directory → VRD → база;
- рекомендации по исправлению;
- CSV и автономный HTML-отчёт;
- фоновое сканирование с прогрессом;
- работа только на чтение: программа не изменяет Apache, публикации или базы 1С.

## Требования

- Windows Server / Windows;
- Windows PowerShell 5.1;
- Apache с публикациями 1С;
- доступ пользователя, запускающего Auditor, к каталогам публикаций и файловым базам.

## Установка

1. Скачайте содержимое репозитория в отдельную папку.
2. Скопируйте `config.example.json` в `config.json`.
3. Укажите путь к `httpd.conf` и корневые каталоги публикаций.
4. Запустите `Check-Syntax.bat`.
5. Если проверки прошли успешно, запустите `Start-Auditor.bat`.
6. Панель откроется по адресу `http://localhost:8787/`.

## Конфигурация

Пример находится в `config.example.json`. Рабочий `config.json` намеренно исключён из Git, чтобы не публиковать сведения о внутренней инфраструктуре.

## Безопасность

Auditor предназначен для диагностики. Статус потенциального внешнего доступа отражает конфигурацию Apache, которую видит программа, и сам по себе не доказывает фактическую доступность сервиса из Интернета: на неё также могут влиять firewall, NAT, reverse proxy и другие уровни инфраструктуры.
